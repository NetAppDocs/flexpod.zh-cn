= 支持的 FlexPod 配置与经验证的 配置
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./../media/


[role="lead"]
FlexPod 架构由本文档中描述的一组规则定义。硬件组件和软件配置必须受 https://ucshcltool.cloudapps.cisco.com/public/hcl["Cisco 硬件兼容性列表（ HCL ）"^]和 http://mysupport.netapp.com/matrix["NetApp 互操作性表工具（ IMT ）"^]支持。

每个 Cisco 验证设计 (CVD) 或 NetApp 验证架构 (NVA) 都代表经过验证的 FlexPod 配置。Cisco 和 NetApp 记录这些配置组合，并通过广泛的端到端测试对其进行验证。偏离这些配置的 FlexPod 部署，如果遵循本文档中的指导方针，且所有组件均在 Cisco HCL 和 NetApp IMT 中列为兼容，则完全受支持。

例如，如果软件，硬件和配置符合本文档中定义的准则，则完全支持添加其他存储控制器或 Cisco UCS 服务器并将软件升级到较新版本。
