== FlexPod Express with NetApp AFF 或 FAS 的软件要求

搭载 NetApp FAS 的 FlexPod Express 的软件要求包括：

* ONTAP 9.1 或更高版本
* Cisco NX-OS 版本 7.0(3)I6(1) 或更高版本
* 在 Cisco UCS 托管配置中，Cisco UCS Manager UCS 4.0(1b)


所有软件必须在 http://mysupport.netapp.com/matrix["NetApp IMT"^]中列出并受支持。某些软件功能可能需要比以前架构中列出的最低版本更新的代码。
