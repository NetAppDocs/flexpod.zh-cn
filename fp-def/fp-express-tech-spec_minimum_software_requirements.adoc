== NetApp AFF/ ASA/ FAS 的 FlexPod Express 软件要求

FlexPod Express 搭配 NetApp AFF/ ASA/ FAS 的软件要求包括：

* ONTAP 9.16 或更高版本
* Cisco NX-OS 版本 10.4(6)M 或更高版本



NOTE: 本节中列出的所有软件版本都是本文档后续章节中列出的硬件组件（NetApp 和 Cisco 组件）的最低要求。

必须在中列出并支持所有软件 http://support.netapp.com/matrix/["NetApp IMT"^]。某些软件功能所需的代码版本可能比先前架构中列出的最低版本更新。
