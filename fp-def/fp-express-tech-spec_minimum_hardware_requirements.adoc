== FlexPod Express 与 NetApp AFF/ASA/FAS

使用 NetApp AFF、ASA 或 FAS 控制器作为底层存储的 FlexPod Express 解决方案的硬件要求包括本节所述的配置。

FlexPod Express 的最低硬件要求如下所示：

* 两个冗余配置的 10Gbps 标准以太网交换机（Cisco Nexus 9200 和 9300 型号）
* 具有基于 CIMC 的独立机架式服务器配置或 Intersight 独立配置的 Cisco UCS C 系列独立机架式服务器，或具有 Cisco Intersight 托管配置 (IMM) 的 Cisco UCS X 系列 Direct。
* 作为双节点群集部署的高可用性 (HA) 对配置中的两个入门级 NetApp AFF (A20、A30 或 C30)、NetApp ASA (A20、A30 或 C30) 或 NetApp FAS (2750 或 2820) 系列控制器
