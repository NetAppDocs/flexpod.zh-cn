[[cisco-ucs-x-series-direct]]
== Cisco UCS X-Series 直连

Cisco UCS X-Series Direct 是一种新的架构，它将一对 Cisco UCS Fabric Interconnect 9108 100G 与 Cisco UCS X9508 Chassis 和 Cisco UCS X-Series Compute 节点集成在一起，以提供 UCS X-Series Direct 解决方案。

有关 Cisco UCS X 系列功能特性的快速概述，请参见 link:https://www.cisco.com/c/en/us/products/collateral/servers-unified-computing/ucs-x-series-modular-system/ucs-x-series-direct-aag.html["Cisco UCS X-Series Direct概览"^]。

Cisco UCS X-Series Direct 包括以下组件：

* Cisco UCS 9108 100G 结构互连
* Cisco UCS X9508 机箱
* Cisco UCS X 系列计算节点
* 可选组件：
+
** PCIe节点和X-Fabric模块
** 第二个 Cisco UCS X9508 机箱，带 X-Series 计算节点、Cisco UCS 9108-100G 智能交换矩阵模块和多达四个 C-Series 机架式服务器





NOTE: 有关 UCS X-Series Direct 的完整技术规范，请参阅此链接： https://www.cisco.com/c/en/us/products/collateral/servers-unified-computing/ucs-x-series-modular-system/ucs-x-series-direct-ds.html["Cisco UCS X-Series Direct 数据表"]。

[[cisco-unified-edge]]
== Cisco Unified Edge

Cisco Unified Edge 是一个 AI 就绪系统，通过融合计算、网络、存储和安全来重新定义边缘计算。模块化设计面向未来、节能且易于维护，可以定制以支持当今的工作负载和用例，同时保持对快速发展的 AI 环境的适应性。

有关 Cisco Unified Edge 功能和特性的简要概述，请参见 link:https://www.cisco.com/c/en/us/products/collateral/servers-unified-computing/unified-edge/unified-edge-at-a-glance.html["Cisco Unified Edge 概览。"^]

Cisco Unified Edge包括以下组件：

* Cisco UCS XE9305 机箱
* 两个带嵌入式 25G 交换机的 Cisco Unified Edge Management Controllers
* 计算节点 - 选择
+
** Cisco UCS XE130c M8 计算节点
** Cisco UCS XE150c M8 计算节点
