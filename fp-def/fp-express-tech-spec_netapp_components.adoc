== NetApp 磁盘架和磁盘



== NetApp FAS

存储控制器至少需要一个 NetApp 磁盘架。所选的 NetApp 磁盘架类型决定了该磁盘架内可用的驱动器类型。

FAS2700 和 FAS2600 系列控制器作为配置提供，包括双存储控制器和位于同一机箱内的磁盘。此配置随 SATA 或 SAS 驱动器提供；因此，除非性能或容量要求需要更多主轴，否则不需要额外的外部磁盘架。

[NOTE]
====
所有磁盘架零件号均适用于带有两个交流电源的空架。有关其他零件号，请咨询您的销售代表。

磁盘驱动器部件号根据您要购买的磁盘的大小和外形而有所不同。有关其他部件号，请咨询您的销售代表。

====

=== E-Series 存储

对于不在机箱中容纳任何驱动器的存储控制器，至少需要一个 NetApp 磁盘架。所选的 NetApp 磁盘架类型决定了该磁盘架内可用的驱动器类型。

E2800 系列控制器作为配置提供，包括双存储控制器以及安装在受支持磁盘架内的磁盘。此配置提供 SSD 或 SAS 驱动器。
