= FlexPod 平台
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
FlexPod 平台有两种：

* *FlexPod Datacenter。*此平台是一个高度可扩展的数据中心基础设施，适用于企业工作负载和应用程序、虚拟化、AI/ML、数据库、SAP HANA、虚拟桌面基础设施 (VDI) 以及公共、私有和混合云工作负载。
* *FlexPod Express.*此平台是一种紧凑型融合基础设施，适用于分支机构和边缘用例。FlexPod Express 具有自己的规范，这些规范记录在 https://docs.netapp.com/us-en/flexpod/fp-def/fp-express-tech-spec_overview.html["FlexPod 快速技术规格"^]中。


本文档提供了 FlexPod 数据中心平台的技术规格。
