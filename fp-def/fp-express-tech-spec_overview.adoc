Karthick Radhakrishnan、Arvind Ramakrishnan、Lindsey Street、Savita Kumari、NetApp

[role="lead"]
FlexPod Express 是一种预先设计的最佳实践架构，基于 Cisco 统一计算系统（Cisco UCS）和 Cisco Nexus 系列交换机构建，存储层使用 NetApp FAS 或 NetApp E-Series 存储构建。FlexPod Express 是运行各种虚拟化虚拟机管理程序和裸机操作系统（OS）以及企业工作负载的合适平台。

FlexPod Express 不仅提供基线配置，还具有灵活进行大小调整和优化的能力，以适应许多不同的用例和需求。本文档根据所使用的存储系统对 FlexPod Express 配置进行分类，即结合 NetApp FAS 的 FlexPod Express 和结合 E-Series 的 FlexPod Express。
