= FlexPod 快速技术规格
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./../media/


[role="lead"]
FlexPod Express 是一种预先设计的最佳实践架构，基于 Cisco 统一计算系统（Cisco UCS）和 Cisco Nexus 系列交换机构建，存储层使用 NetApp AFF、ASA 或 FAS 入门级存储系统构建。FlexPod Express 是运行各种虚拟化虚拟机管理程序和裸机操作系统（OS）以及企业工作负载的合适平台。

FlexPod Express 不仅提供基线配置，还提供灵活性来调整和优化，以适应许多不同的用例和要求。
