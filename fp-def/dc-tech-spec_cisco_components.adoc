[[cisco-ucs-x-series-modular-system]]
== Cisco UCS X-Series Modular System

Cisco UCS X 系列模块化系统从 Cisco UCS X9508 服务器机箱开始，该机箱设计为适应性强且面向未来。机箱具有统一的以太网交换矩阵，其中包含用于其他技术的 Cisco UCS 智能交换矩阵模块和 Cisco UCS X-Fabric 技术。机箱顶部背面有两个智能交换矩阵模块，它们将机箱连接到上游 Cisco UCS 6400、6500 和 UCS 6600 系列交换矩阵互联。

有关 Cisco UCS X 系列功能特性的快速概述，请参见 link:https://www.cisco.com/c/en/us/products/collateral/servers-unified-computing/ucs-x-series-modular-system/ucs-x-series-modular-system-aag.html["Cisco UCS X系列模块化系统概览"^]。

Cisco UCS X215c M8、Cisco UCS X210c 和 Cisco UCS X410c 计算节点通过在单个外形中提供计算密度、存储容量和可扩展性，同时提供刀片服务器和机架式服务器的功能。

Cisco UCS X440p PCIe 节点支持使用 PCIe Gen 4.0 和 Cisco UCS X9416 X-Fabric 模块添加 GPU。Cisco UCS X580p PCIe 节点支持使用 PCIe Gen 5.0 和 Cisco UCS X9516 X-Fabric 模块添加 GPU

有关 Cisco UCS X 系列模块化系统解决方案组件的详细信息，请参见上述部分中每个组件的技术规格。


NOTE: 有关 Cisco UCS X 系列模块化系统的完整技术规格，请参阅以下链接：link:https://www.cisco.com/c/en/us/products/servers-unified-computing/ucs-x-series-modular-system/datasheet-listing.html["Cisco UCS X-Series Modular System"^]



[[cisco-ucs-x-series-direct-options]]
== Cisco UCS X-Series Direct 选项

Cisco UCS X-Series Direct 是一种新的架构，它将一对 Cisco UCS Fabric Interconnect 9108 100G 与 Cisco UCS X9508 Chassis 和 Cisco UCS X-Series Compute 节点集成在一起，以提供 UCS X-Series Direct 解决方案。

有关 Cisco UCS X 系列功能特性的快速概述，请参见 link:https://www.cisco.com/c/en/us/products/collateral/servers-unified-computing/ucs-x-series-modular-system/ucs-x-series-direct-aag.html["Cisco UCS X-Series Direct概览"^]。

Cisco UCS X-Series Direct 包括以下组件：

* Cisco UCS 9108 100G 结构互连
* Cisco UCS X9508 机箱
* Cisco UCS X 系列计算节点
* 可选组件：
+
** PCIe节点和X-Fabric模块
** 第二个 Cisco UCS X9508 机箱，带 X-Series 计算节点、Cisco UCS 9108-100G 智能交换矩阵模块和多达四个 C-Series 机架式服务器




有关 Cisco UCS X-Series Direct 解决方案组件的详细信息，请参见上述部分中每个组件的技术规格。


NOTE: 有关 Cisco UCS X-Series Direct 的完整技术规格，请参阅以下链接： https://www.cisco.com/c/en/us/products/collateral/servers-unified-computing/ucs-x-series-modular-system/ucs-x-series-direct-ds.html["Cisco UCS X-Series Direct 数据表"]。
