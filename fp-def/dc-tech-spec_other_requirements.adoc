= 其他要求
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
FlexPod Datacenter 的其他要求包括以下内容：

* 如果您计划使用 VMware ESXi 作为虚拟机管理程序，请参阅link:https://compatibilityguide.broadcom.com/["Broadcom 兼容性指南"]以验证您的硬件和软件组件是否受支持。
* 对于基于 OpenShift 的部署，请确保您拥有与 OpenShift 兼容的必要硬件和软件组件。有关详细信息，请参见 link:https://catalog.redhat.com/en/search["OpenShift 目录"]。
