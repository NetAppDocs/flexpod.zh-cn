= FlexPod 平台
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./../media/


[role="lead"]
FlexPod 平台有两种：

* *FlexPod Datacenter.*该平台是一种高度可扩展的数据中心基础设施，适用于企业工作负载和应用、虚拟化、AI/ML、数据库、SAP HANA、VDI 以及公有云和私有云。FlexPod Datacenter 拥有自己的规范，这些规范记录在  https://docs.netapp.com/us-en/flexpod/fp-def/dc-tech-spec_solution_overview.html["FlexPod 数据中心技术规格"^] 中。
* * FlexPod Express* 。此平台是一个紧凑型融合基础架构，面向远程办公室和边缘使用情形。


本文档提供了 FlexPod 快速平台的技术规格。
