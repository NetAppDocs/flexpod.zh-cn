= FlexPod 规则
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./../media/


[role="lead"]
该 FlexPod 设计支持灵活的基础设施架构，该架构包括各种硬件组件和软件版本。

使用规则集作为构建或组装有效 FlexPod 配置的指南。本文档中列出的数字和规则表示 FlexPod 的最低要求，可根据不同环境和用例的需求，通过在所包含的产品系列中使用受支持的产品进行扩展。
