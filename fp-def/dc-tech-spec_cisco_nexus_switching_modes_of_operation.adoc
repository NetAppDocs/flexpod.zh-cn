= Cisco Nexus 切换操作模式
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
各种 Cisco Nexus 产品可以用作给定 FlexPod 部署的交换组件。这些选项中的大多数都利用了 Cisco NX-OS 软件。Cisco Nexus 系列交换机在其产品线中提供不同的功能。本文档稍后将详细介绍这些功能。

Cisco 在软件定义网络领域的产品被称为以应用为中心的基础设施 (ACI)。支持 ACI 模式（交换矩阵模式）的 Cisco Nexus 产品线也可以部署在 NX-OS 模式下。

Cisco ACI 的目标部署对象是侧重于特定应用程序要求的数据中心部署。应用程序通过一系列配置文件和合同进行实例化，这些配置文件和合同允许从主机或虚拟机（ VM ）一直通过网络连接到存储。

FlexPod Datacenter 已通过 Cisco Nexus 交换机的两种运行模式验证。有关 ACI 和 NX-OS 模式的详细信息，请参见以下 Cisco 页面：

* http://www.cisco.com/c/en/us/solutions/data-center-virtualization/application-centric-infrastructure/index.html["Cisco 以应用程序为中心的基础架构"^]
* https://www.cisco.com/site/us/en/products/networking/cloud-networking/nx-os/index.html["Cisco NX-OS 软件"^]
