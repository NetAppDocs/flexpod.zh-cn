== FlexPod Express 与 NetApp AFF/ASA/FAS 的连接要求

FlexPod Express 与 NetApp AFF/ASA/FAS 的连接要求通常包括：

* NetApp 存储控制器必须直接连接到 Cisco Nexus 交换机。
* 对于 Cisco UCS X-Series Direct 部署，NetApp 存储控制器可以直接连接到嵌入式交换矩阵互联。
* 不能在核心 FlexPod 组件之间实时放置任何其他设备。
* 将 Cisco Nexus 9000 系列交换机连接到 NetApp 存储控制器需要虚拟端口通道 (vPC)。
* 虽然不需要，但建议在整个环境中启用巨型帧支持。


有关每个拓扑特定的连接要求，请参见 link:https://docs.netapp.com/us-en/flexpod/fp-def/fp-express-tech-spec_flexpod_express_topologies.html["FlexPod Express 拓扑"^] 部分。
