= FlexPod 数据中心技术规格
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
该 FlexPod 平台是一种预先设计的最佳实践数据中心架构，基于 Cisco 统一计算系统（Cisco UCS）、Cisco Nexus 和 MDS（用于 FC）系列交换机以及 NetApp 存储控制器（AFF、ASA、FAS 或 AFX 系统）构建。

FlexPod 是运行各种虚拟化虚拟机管理程序、裸机操作系统、容器化环境和企业工作负载的合适平台。FlexPod 不仅提供基线配置，还提供调整大小和优化的灵活性，以适应许多不同的用例和要求。


NOTE: 在订购完整的 FlexPod 配置之前，请参阅 http://www.netapp.com/us/technology/flexpod["NetApp FlexPod 主页"^]以了解这些技术规范的最新版本。
