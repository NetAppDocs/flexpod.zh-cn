= 结论
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
将 FlexPod Edge 与软件定义的存储一起部署，为客户提供了在边缘获得企业数据服务的实用途径。该架构将 Cisco 的紧凑型集中管理统一边缘平台与 ONTAP 的成熟数据服务相结合，在单个机箱内实现软件定义的存储，可支持创建和操作数据的本地工作负载。
